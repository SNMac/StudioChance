1. 피커를 표시할 때 쓰던 버튼이 피커 표시용이 아니었음. 눌렀을 때 사용자가 멤버로 있는 점포의 목록이 뜨고, 어떤 점포의 일정들을 볼건지 필터링하는 용도(애플 캘린더의 캘린더 선택 버튼과 비슷)
2. 지금 스크롤을 맨 위나 맨 아래로 해서 늘어지는 효과가 뜰 때, 해당 날짜의 스크롤만 늘어지는 효과가 남. 이전처럼 전체 날짜의 스크롤이 늘어져야 함
3. 아직 3일 캘린더의 시간 표시 영역에서 라벨이 구분선과 수평 정렬되어있지 않음.
4. 월간 캘린더 선택 날짜 이동시 선택 UI가 이동하는 애니메이션이 지금 날짜부터 선택한 날짜로 이어지듯이 애니메이션이 있어야 하는데, 선택한 날짜에 먼저 애니메이션이 뜨다가 지금 날짜부터 선택한 날짜로 애니메이션이 이어짐. 그리고 애니메이션으로 뜨는 사각형?에 코너값이 적용되어있지 않음.
5. 지금 예를 들어 현재 날짜 3월에서 작년 12월로 갔다가 오늘 버튼을 누르면 네비바 연/월 UI가 3월로 표시됐다가 1, 2, 3으로 됨. 오늘 버튼뿐만의 문제가 아닌, 캘린더를 선택 날짜로 이동할 때 이런 현상 모두 발생.
6. 3일 캘린더에서 스크롤시 고정되어있는 구분선은 좌측 시간 표시 영역과 일정 표시 영역을 나누는 구분선과, 요일과 종일을 나누는 구분선, 종일과 시간, 일정 영역을 나누는 구분선 뿐. 나머지는 스크롤하면서 날에 맞춰 스크롤되어야함. 날짜별로 갖고있다고 생각하면 좋을듯.
7. 현재 시간 표시 UI의 라벨이 아직 시간 표시 라벨과 수직 정렬되어있지 않음. 좌측으로 더 이동해야함.
