2. 월간 캘린더에서 선택한 날짜 자체에 대한 UI 효과로 label색 둥근 사각형을 표시하고 있는데, 오늘 날짜에 대해선 그 안에 systemBackground으로 24\*24 크기의 동그라미를 넣고, 그 안에 숫자를 label색으로 넣고싶어. 그리고 오늘 날짜 이동 버튼과 캘린더 피커 표시 버튼도 똑같이 24\*24로 크기로 표시하게 하고.(터치 영역은 동일) 만약 날짜 선택이 오늘 날짜에서 변경된다면, 오늘 날짜의 동그라미는 배경색이 label로, 글자 색이 systemBackground로 변경되도록 하고.
3. 지금 3일 캘린더 스크롤이 한번에 3일씩 되지만, 2일씩 겹쳐서 표시해서 3일을 만들고 있어. 예를들면 현재 20, 21, 22가 표시된다면 스크롤을 한번 했을 때 20, 21, 22가 다 넘어가고, 다음 페이지엔 21, 22, 23이 있으면서 3일 캘린더를 만드는거야. 난 이걸 의도한게 아니야. 내가 의도한건 20, 21, 22가 넘어간다면 다음 날짜로 스크롤을 했을 때, 20만 넘어가고 23이 들어오면서 21, 22, 23이 보이는거야. 그리고 스크롤이 지금은 항상 한 페이지 단위(20, 21, 22 -> 21, 22, 23)로 하고있는데, 스크롤을 세게 하면 그만큼 가속도가 붙어서 더 넘어가도 돼. 단, 아무곳에서나 스크롤이 멈추는게 아닌, 요일 단위로 멈춰야 해.
