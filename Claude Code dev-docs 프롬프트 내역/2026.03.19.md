  - 높이는 네비바 높이, 너비는 내용만큼
- 우측엔 calendar.circle 이미지 버튼과 오늘 일자가 써져있고 동그라미로 감싸진 버튼(예: 3월 19일인 경우 - 19, 배경 label, 숫자 systemBackground 색상)
  - calendar.circle 버튼을 누르면 어느 날짜로 이동하고싶은지 고르는 picker가 뜸
  - 오늘 일자가 써져있는 버튼을 누르면 오늘 날짜로 이동함
  - 숫자 폰트는 bodyMedium
  - 모두 너비는 44, 높이는 네비바 높이 크기로 터치 범위를 가지지만, 이미지 크기, 동그라미 크기는 20*20

2. 월간 캘린더
- 몇월인지 알려주는건 네비게이션 바에 있으므로 별도 구현 X
- 배경은 systemBackground 색상
- 상단에 요일 표시
  - 일월화수목금토 고정
  - 폰트는 labelMedium
  - 일은 systemRed, 토는 systemBlue
- 요일 표시 아래 일 표시
  - 항상 5열 표시
  - 폰트는 labelLarge에서 크기만 16
  - 일요일 날짜 색상 systemRed, 토요일 날짜 색상 systemBlue
  - 이전 달, 다음달의 날짜가 보이는 경우, 불투명도 30% (예: 2025년 12월의 경우 11월 30일과 1월 1, 2, 3일이 보임)
  - 기본적으로 3일 캘린더에서 보여지는 날짜, 총 3개 날짜가 선택되어있음
    - 선택된 날짜들의 크기는 40*40, 코너값은 8
    - 3일 캘린더에서 보여지는 날짜의 첫번째 날짜에 해당하는 곳의 색상은 토, 일에 상관없이 숫자는 systemBackground, 배경은 label
    - 나머지 2일에 해당하는 곳의 배경 색상은 secondarySystemFill, 숫자는 원래 색상 그대로
