이제 캘린더 일정 셀을 구현할거야. 사진에서 3일 캘린더 일정 영역에 있는 초록색, 노란색이 구현할 셀이야. 셀만 있는 사진도 첨부했어.
셀은 3가지 상태로 구분돼.
1. 예약 확정 (체크표시 - CupertinoIcons.checkmark_circle)
2. 입금 대기 (점선 원 - CupertinoIcons.circle)
3. 예약 취소 (원에 사선 - assets/images/icons/circle_slash.svg, flutter_svg 사용해야할듯)
1번과 2번 아이콘은 Light 폰트를 사용해야해. 3번 아이콘은 이미 적용된 사진이야.
셀에는 두께 0.5, 색상 systemBackground의 외곽선이 있어. 코너값은 4야.
색상들은 아직 추가되지 않았는데, 아래 색상들을 color.dart에 넣어줘:
- 배경색
	- redBackground(#FF9E99)
	- orangeBackground(#FFD599)
	- yellowBackground(FFEB99)
	- greenBackground(#AEEABD)
	- blueBackground(#99CAFF)
	- indigoBackground(#AEADEB)
	- purpleBackground(#D7A9EF)
- 메인색
	- redForeground(#FF3B30)
	- orangeForeground(#FF9500)
	- yellowForeground(#FFCC00)
	- greenForeground(#34C759)
	- blueForeground(#007AFF)
	- indigoForeground(#5856D6)
	- purpleForeground(#AF52DE)
- 라벨색
	- redLabel(#990800)
	- orangeLabel(#995900)
	- yellowLabel(#997A00)
	- greenLabel(#207936)
	- blueLabel(#004999)
	- indigoLabel(#1F1E7B)
	- purpleLabel(#5E1980)

왼쪽에 너비 4만큼 색상이 더 진한 부분(색상 ~Background)이 있고, 나머지 영역(색상 ~Foreground)엔 라벨(색상 ~Label)들이 들어가. 아이콘은 왼쪽 더 진한 부분의 위, 왼쪽에서 4만큼 떨어져 있고, 그 뒤로 텍스트는 2.5만큼 떨어져있어. 텍스트는 세로로 2개인데, 위에는 '예약자명 · 예약인원'이 들어가고, 아래는 전화번호(XXX-XXXX-XXXX)가 들어가.

셀의 최소 높이는 35가 되어야 하는데, 지금 3일 캘린더 시간대 사이 최소 높이가 40인지 모르겠네. 만약 40이 아니라면, 그렇게 되도록 확대/축소 범위를 수정해줘.
셀은 '종일' 영역에 있다면 왼쪽 구분선에서 1만큼, 오른쪽 구분선에서 8만큼 떨어져. 위쪽 구분선에선 1만큼, 아래쪽 구분선에선 4만큼 떨어져야 해.
셀이 시간대 영역에 있다면 왼쪽 구분선에서 1만큼, 오른쪽 구분선에서 8만큼 떨어지는건 동일하지만, 위쪽 구분선과는 0.5, 아래쪽 구분선과는 0.5만큼 떨어져야 해. 3일 캘린더 시간대 사이 높이가 40일 때 이렇게 offset을 주면 높이가 35가 돼.

같은 날짜 같은 시간대에 일정이 여러개가 있다면 겹치게 되는데, 우선 이건 여기까지 구현하고 나서 진행해보자.
