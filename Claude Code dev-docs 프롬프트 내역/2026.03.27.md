이제 이벤트가 겹칠 때를 구현할거야. 동일 시간 시작 이벤트 기준 첨부한 사진에서 가운데 초록색, 노란색 셀처럼 겹치는건데, 노란색 셀의 우측은 초록색 셀과 똑같이 우측 구분선과 8 간격을 갖고있고, 위쪽은 동일해. 노란색 셀의 너비는 최소한 이름만 보이게끔(단, 이름이 3자를 초과하는 경우 3자만 보이게) 차지하고, 그 안의 내용을 줄바꿈 없이 사진처럼 그냥 잘리게끔 할거야. 초록색 셀의 이름 3자가 보이게끔 쌓여야 해. 쌓이는 순서는 동일 시작 시간 이벤트 기준 더 긴게 위에 쌓이는거야. 만약 A 이벤트가 더 먼저 시작하고, A 이벤트 보다 더 늦게 시작하는 B 이벤트가 진행되는 A 이벤트보다 일찍 끝난다면 A 이벤트 위에 B 이벤트가 쌓여. B이벤트가 더 늦게 끝난다고 해도 B 이벤트가 먼저 쌓여. 동일 시간에 시작하고 동일 시간에 끝난다면 그냥 사용자가 최근에 추가한 이벤트가 위에 가도록 할거야.
동일 시간에 3개가 겹칠 때는 어떻게할지 아직 고민이야. 추천해줄 수 있어?
