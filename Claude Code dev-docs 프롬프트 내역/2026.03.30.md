안드로이드에서 확인해보니 예약 정보 모달이 화면 너비를 모두 채우지 않고, 이름이 보이는 영역보다 살짝 넓게 표시돼. 그리고 드래그해서 높이를 최대로 늘릴수도 없어.
또, 여러 개 중첩된 예약 셀을 눌렀을 때 뜨는 예약 리스트 모달이 높이가 최대로 뜨고, 모달 Grabber도 보이지 않아. 이것도 절반정도로 최초에 표시되고, 사용자가 위아래로 스와이프해서 높이를 최대/절반 이렇게 조절할 수 있으면 좋겠어. 이건 iOS에서도 그렇더라고.
사실 정보 모달은 추후에 입력폼이 들어갈건데, 거기서 특정 입력칸이 모두 보일 때까지만 최초에 보이도록 할거야. 딱 절반은 아니야. 피그마 상으론 safeArea 제외 537이야. 근데 이 수치를 하드코딩하는게 나을지, 추후 입력폼에서 특정 입력칸의 위치를 파악하고 그만큼 표시하게 하는게 나을지는 잘 모르겠어.

Flutter를 기존 3.38.5에서 3.41.6으로 업데이트했어. 그래서 showCupertinoSheet 메서드에선 topGap이라는 프로퍼티 값을 통해 높이를 조절 가능하고, showDragHandle 프로퍼티를 통해 Grabber를 보여줄 수 있어.
