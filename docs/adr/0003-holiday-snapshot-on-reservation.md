# 예약에 공휴일 스냅샷을 저장한다 (D12 확장)

D12는 점포 요금이 바뀌어도 기존 예약 가격이 수정 과정에서 저절로 바뀌지 않도록 요금표 스냅샷을 저장한다. 공휴일 달력도 같은 외부 데이터라서(임시공휴일 지정, 예측 공휴일이 공식 공휴일로 교체됨) 같은 원칙을 적용한다. 예약에는 가격 계산 때 공휴일로 판정한 날짜만 저장한다. 다뤘던 날짜 범위는 저장된 예약의 시작·종료 시각으로 알 수 있다.

같은 점포·공간에서 예약을 수정하면 저장된 예약 기간 안의 날짜는 스냅샷으로, 밖의 날짜는 현재 공휴일 달력으로 판정한다. 공휴일 판정은 요금표와 달리 날짜에 묶여 있어서, 날짜를 옮기면 원래 날짜의 판정은 새 날짜에 의미가 없기 때문이다. '현재 요금 적용'은 요금표나 공휴일 판정 중 하나라도 현재와 다르면 제안하고, 누르면 둘 다 갱신한다. 이 판단은 `keepsPriceSettingFor`처럼 엔티티 extension 하나에 두고 상세 모달과 `ReservationUseCaseImpl`이 공유한다.

## Considered Options

- **스냅샷 없이 매번 현재 공휴일 달력으로 계산**: 단순하지만, 메모만 고쳐도 가격이 공휴일 요금으로 바뀌는 D12의 예외가 생긴다.
- **날짜 범위가 바뀌면 공휴일 스냅샷 전체를 버림**: 같은 날 안에서 시간만 바꿔도 판정이 갱신되어 원칙과 어긋난다.
