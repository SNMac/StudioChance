# Triage 라벨

스킬들은 다섯 가지 기본 triage 역할 이름으로 말한다. 이 파일은 각 역할을 이 저장소 이슈 트래커의 실제 라벨 문자열에 대응시킨다.

| mattpocock/skills의 라벨 | 이 저장소의 라벨      | 의미                                 |
| ------------------------ | --------------------- | ------------------------------------ |
| `needs-triage`           | `needs-triage`        | 메인테이너가 검토해야 함             |
| `needs-info`             | `needs-info`          | 작성자의 추가 정보를 기다리는 중     |
| `ready-for-agent`        | `ready-for-agent`     | 명세 완료, 에이전트가 단독 작업 가능 |
| `ready-for-human`        | `ready-for-human`     | 사람이 직접 구현해야 함              |
| `wontfix`                | `wontfix`             | 처리하지 않음                        |

스킬이 역할을 언급하면(예: "apply the AFK-ready triage label") 이 표에서 대응하는 라벨 문자열을 쓴다.

실제로 쓰는 라벨이 다르면 "이 저장소의 라벨" 열을 고친다.
